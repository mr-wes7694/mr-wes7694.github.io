Conway's Game of Life

A programming project based on the cellular automaton created by mathematician John Conway. The program holds a grid of live and dead cells and calculates each new generation by counting every cell's eight neighbors and applying four rules.

Those four simple rules can produce surprisingly complex patterns, which makes this a good exercise in working with grids, loops, and program state. The grid at the top of this page follows the same rules.

UnderpopulationA live cell with fewer than 2 live neighbors dies.
SurvivalA live cell with 2 or 3 live neighbors stays alive.
OverpopulationA live cell with more than 3 live neighbors dies.
ReproductionA dead cell with exactly 3 live neighbors comes alive.
